# 呼和浩特三肥罐四阀水肥系统实施说明

## 1. 当前实现

系统采用两级决策：

1. 农艺层根据作物、生育期、墒情、田间持水量、ET₀、降雨、土壤EC、土检N/P/K等级和本阶段累计施肥量，输出本次水量及纯N、P₂O₅、K₂O；
2. 执行层根据母液实测浓度换算A/B/C罐体积，以主水和三路肥液流量计的累计量控制四个电磁阀。

三个肥罐默认定义为：

| 罐 | 目标养分 | 示例浓度 |
|---|---|---:|
| A | N | 100 g/L |
| B | P₂O₅ | 80 g/L |
| C | K₂O | 120 g/L |

示例浓度只用于软件仿真，上机前必须修改 [hardware.json](configs/hardware.json)。若一个肥料同时含两种以上养分，不能再按独立N/P/K罐简单计算，必须使用养分浓度矩阵求解。

## 2. 管路要求

```text
水源→泵→过滤器→主流量计→主水阀────────────────→主管→田间
                              ↑      ↑      ↑
                         止回+A阀 止回+B阀 止回+C阀
                              ↑      ↑      ↑
                         注入装置  注入装置  注入装置
                              ↑      ↑      ↑
                         A流量计  B流量计  C流量计
                              ↑      ↑      ↑
                            A罐     B罐     C罐
```

肥罐常压时不能依赖电磁阀自行向有压主管注入，必须配置文丘里吸肥器或计量泵。每路还应配置过滤器、止回阀、防虹吸装置和手动截止阀。建议把主水阀放在能保证注肥器压差的位置，由水力设计确定。

## 3. 推荐作业顺序

```text
自检 → 开主水 → 确认主流量 → 清水预冲
→ 开A阀至A累计体积达标 → 关A → 清水隔离
→ 开B阀至B累计体积达标 → 关B → 清水隔离
→ 开C阀至C累计体积达标 → 关C
→ 清水灌溉及后冲 → 主水累计达标 → 关主水
```

默认禁止两个肥阀同时开启。磷肥与含钙、高镁或高浓度硫酸盐的母液尤其不能在高浓度状态直接接触。

## 4. 必须实现的联锁

- 主水无流量：立即关闭A/B/C，报警；
- 某肥阀打开但肥路无流量：关闭该肥阀，报警；
- 肥路流量异常增大：关闭全部肥阀，保持短时清水冲洗后停机；
- 累计母液达到目标：立即关对应阀；
- 主水EC超过上限：关闭全部肥阀；
- 流量计断线、罐低液位、压力异常：禁止注肥；
- 控制器重启后默认四阀全关，不自动恢复未完成的施肥；
- 必须有独立急停和手动总阀。

## 5. 当前训练能力边界

现有机器学习部分仍只有USDA玉米81条小区水氮响应数据，跨年R²为−0.10，不能称为效果良好的本地优化模型。NASA POWER、Open-Meteo、SoilGrids、遥感和地形数据可以增加输入信息，但它们没有你地块的“水肥处理—产量/品质”标签，不能单独训练出可靠处方。

当前可用于试验的是物理水量平衡＋农艺阶段预算＋流量闭环控制。取得至少一个生长季的本地数据后，才应训练处方优化器。

## 6. 本地训练数据最低要求

每条记录至少包含：地块边界、作物/品种、生育期、20/40/60 cm墒情、土壤化验、井水化验、逐日天气、每次主水体积、A/B/C母液浓度和实际体积、故障、最终产量及品质。每种作物建议5个水肥处理×3重复，连续2年以上；验证必须按年份或整地块留出，不能随机混分。

## 7. 软件入口

```powershell
# 获取某块农田环境先验
python scripts/fetch_environment.py --latitude 40.72 --longitude 111.55

# 生成一亩马铃薯四阀工作单
python scripts/build_job.py --crop 马铃薯 --stage 块茎膨大 --area-mu 1 `
  --soil-moisture-20 18 --soil-moisture-40 21 --field-capacity 28 `
  --eto 5.5 --rain-forecast 0 --soil-ec 1.0 `
  --soil-test-n-level low --soil-test-p-level low --soil-test-k-level low

# 无硬件仿真
python scripts/simulate_controller.py
```

`controller.py`目前是硬件无关状态机。接ESP32或PLC时，应只更换GPIO、脉冲流量计和通信适配层，不应把安全联锁删除。
