# 呼和浩特水肥一体化V2模型报告

## 模型性质

V2是环境驱动的多输出策略蒸馏模型：以FAO-56水量平衡、四种作物分阶段N/P/K预算和安全联锁为教师策略，使用真实呼和浩特历史天气和当地土壤先验生成监督样本，再训练ExtraTrees同时预测每亩水、纯N、P₂O₅和K₂O。

它不是产量模型。没有本地“水肥处理—产量/品质”标签，当前无法证明增产效果或求解真实最优处方。

## 数据与划分

| 项目 | 内容 |
|---|---|
| 天气 | NASA POWER呼和浩特2015—2025逐日温度、湿度、风、降雨、辐射 |
| 派生天气 | FAO-56 ET₀、未来2日降雨、7日雨量/ET₀、14日积温、连续干旱天数 |
| 土壤 | SoilGrids土默川西、中和呼市东南代表性剖面 |
| 作物 | 马铃薯、甜菜、玉米、向日葵及生育阶段 |
| 传感器情景 | 20/40/60 cm墒情、EC、田间持水量、土检等级、已施肥量 |
| 总样本 | 39,600 |
| 训练集 | 2015—2022 |
| 验证集 | 2023 |
| 独立测试集 | 2024—2025 |

## 独立测试结果

| 输出 | MAE | RMSE | R² |
|---|---:|---:|---:|
| 水量 m³/亩 | 0.3520 | 1.1787 | 0.9755 |
| N kg/亩 | 0.0341 | 0.1452 | 0.8476 |
| P₂O₅ kg/亩 | 0.0214 | 0.0855 | 0.8723 |
| K₂O kg/亩 | 0.0242 | 0.1357 | 0.7756 |

灌溉开关判断准确率为93.15%。模型外仍设置物理安全门：墒情/降雨不通过则禁止灌水；主水不运行、EC超限、施肥间隔不足、土检为高或阶段预算用完时，相应肥阀禁止开启。

## 使用边界

土壤栅格和模拟传感器情景是区域先验，不能替代地块实测。上线前必须标定田间持水量、母液浓度、四个流量计、主管压力与流量范围。积累本地产量和品质标签后，应训练V3产量响应/多目标优化模型，并按整年份和整地块独立测试。
