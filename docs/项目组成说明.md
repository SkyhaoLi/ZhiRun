# 智润农田水肥与水泵控制项目组成说明

## 一、项目总览

本项目由华为 Atlas 200I DK A2、ESP32-S3 水泵控制器、公网服务器、传感器和水肥模型组成。

核心原则：

- 华为 Atlas 负责环境数据采集、网络通信和命令转发。
- ESP32 只负责水泵的实际控制和状态反馈。
- 公网服务器负责网页、命令队列和设备状态保存。
- 水肥模型负责灌溉和施肥策略建议。

## 二、硬件组成

### 1. 华为 Atlas 200I DK A2

职责：

- 通过 RS485 读取环境传感器。
- 通过以太网连接公网服务器。
- 从服务器获取控制命令。
- 通过 USB 串口把控制命令发送给 ESP32。

### 2. ESP32-S3 水泵控制器

职责：

- 控制水泵 GPIO 和继电器/驱动模块。
- 执行手动开泵、关泵。
- 执行自动灌溉逻辑。
- 根据土壤水分判断自动开关泵。
- 通过串口返回 `STATE` 状态。

### 3. 传感器

当前主要采集：

- 土壤水分
- 土壤温度
- 土壤 pH
- 土壤氮、磷、钾
- 空气温度和湿度
- CO2
- 光照
- 风速
- 雨量

## 四、数据和控制链路

### 环境数据上报

```text
传感器 -> RS485 -> Atlas -> 以太网 -> 公网服务器 -> Web 页面
```

### 手动开关泵

```text
Web 点击开阀/关阀
    -> 公网服务器命令队列
    -> Atlas 轮询命令
    -> USB 串口
    -> ESP32 执行 GPIO
    -> ESP32 返回 STATE
    -> Atlas 上报状态
    -> Web 更新显示
```

### 自动灌溉

```text
土壤传感器
    -> Atlas 采集土壤水分
    -> Atlas 通过串口发送给 ESP32
    -> ESP32 根据阈值自动控制水泵
    -> ESP32 返回自动模式和水泵状态
```

## 五、职责边界

| 组件 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| Atlas | 传感器采集、网络通信、串口转发 | 水泵最终控制逻辑 |
| ESP32 | 水泵 GPIO、手动控制、自动控制、状态反馈 | 网页和数据库 |
| 公网服务器 | API、命令队列、状态保存、网页 | 直接控制 GPIO |
| Web 页面 | 用户操作和状态展示 | 直接连接 ESP32 |
| 水肥模型 | 灌溉和施肥建议 | 实时继电器驱动 |

## 六、配置和安全

- 真实服务器地址、设备令牌、Wi-Fi 密码和 SSH 密码不应提交到 GitHub。
- 使用 `.env.atlas.example` 复制出实际配置文件。
- 不要上传 `.pio/`、日志、固件备份、私钥和会话 Cookie。
- ESP32 当前通过 USB 串口连接 Atlas，不通过路由器直接接收水泵命令。
